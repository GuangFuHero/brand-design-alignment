# Design Guidelines

## Core Principles
1. **Accessibility First**: Default target audience 35-50 years old.
2. **Information Formatting**: Immediate understanding of on-site needs.
3. **Mobile First**: Design for mobile, scale to desktop.

## Typography
- **Mobile Base**: 16px (sm)
- **Desktop Base**: 20px (md) (1.25x of mobile)
- **Small Text**: Use `sm` or smaller only for special notes.

## Interactive Elements
- **Touch Target**: Minimum height 36px for all buttons, tabs, and text fields to ensure ease of use.
