


## 🎨 Workflow

1.  **Figma**: Designers update styles in Figma.
2.  **Export**: Export tokens to `tokens/` directory.
3.  **Build**: Run `npm run build` to generate new CSS.
4.  **Commit**: Push changes to GitHub.
